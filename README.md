# Customer Onboarding API

AI-Driven Development Lifecycle (AIDLC) demo project.

## Technology Stack

- Java 21
- Spring Boot 3.5
- H2 Database
- Swagger/OpenAPI
- JUnit 5
- Mockito

## Features

- Create Customer
- Get Customer
- Get All Customers
- Update Customer
- Delete Customer

## Run

mvn spring-boot:run

## Swagger

http://localhost:8080/swagger-ui/index.html
